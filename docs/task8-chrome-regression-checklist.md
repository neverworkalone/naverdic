- [ ] 헤더의 버전이 `7.0`으로 표시되는지 확인한다.

## 툴바 팝업

- [ ] 확장 아이콘을 클릭했을 때 360px 팝업이 초기 92px 높이로 한 번에 표시된다.
- [ ] 입력창이 자동 포커스되고 Enter/검색 버튼으로 검색된다.
- [ ] 로딩·결과 없음·네트워크 오류 상태가 결과 영역에 표시된다.
- [ ] 검색 결과가 있는 상태에서 새 단어를 검색해도 빈 팝업 상태가 중간에 노출되지 않는다.
- [ ] 검색을 연속으로 실행했을 때 오래된 응답이 최신 결과를 덮어쓰지 않는다.
- [ ] 사전 결과가 Figma 카드 구조로 표시되고 콘텐츠가 최대 높이를 넘으면 footer 포함 popup body 전체가 스크롤된다.
- [ ] 발음 버튼을 눌러 재생되며, 재생 불가 URL에서는 버튼과 오류 문구가 사라진다.
- [ ] 설정 링크가 새 옵션 페이지로 이동하고 도움말 링크가 새 탭에서 열린다.

## 인라인 팝업

- [ ] 단어 더블클릭과 문장 드래그가 각각 사전/번역 팝업을 연다.
- [ ] 번역 팝업에 `번역` 제목 행이 노출되지 않는다.
- [ ] 사전 팝업은 360px, 번역 팝업은 440px 폭을 유지한다.
- [ ] 긴 번역/사전 결과는 최대 높이와 내부 스크롤을 사용한다.
- [ ] 선택 영역이 네 방향 가장자리에 있을 때 팝업이 뷰포트 밖으로 나가지 않는다.
- [ ] 페이지 스크롤·확대·iframe 안에서도 팝업이 선택 위치를 따라간다.
- [ ] 팝업 바깥 클릭과 Escape로 닫힌다.
- [ ] Shadow DOM 밖의 페이지 스타일이 팝업 내부에 영향을 주지 않는다.
- [ ] 연속 선택 중 이전 요청의 늦은 응답이 표시되지 않는다.
